
# Nomad Pack

Nomad Pack is a templating and packaging tool for [HashiCorp Nomad](https://developer.hashicorp.com/nomad). It has the ability to pull from remote registries and deploy multiple resources together, like Helm.

Use Nomad Pack to:

- Deploy popular applications to Nomad.
- Re-use common patterns across internal applications.
- Find and share job specifications with the Nomad community. Visit the [Nomad Pack Community Registry repository](https://github.com/hashicorp/nomad-pack-community-registry) to learn more.
